# 공모전 AI 영상·이미지 출품 파이프라인

시작 전에 `references/lessons.md`(실패 교훈 표)와 `references/checklists.md`(단계별 점검표)를 읽는다. 점검표에 ✗가 있으면 다음 단계로 가지 않는다.

## 순서

1. **규정** — 공식 공고와 공식 폼 첫 화면까지 직접 읽고 규정 메모를 만든다: 마감, 길이, 비율·해상도, 제출물 목록, 필수 문구, AI 표기 칸, 칸별 글자 수, 공개 조건 세 줄(발표 전 공개 금지·공개 유지 기간·마감 뒤 수정 금지). 작업 규칙과 충돌하면 사람 결정을 받는다.
2. **대본** — 주인공 목표 하나와 반전, 첫 3~5초에 누가·무엇을·왜, 대사형은 30초마다 대사 6~9줄, 행동 이유는 대사로, 해설은 자막(목소리는 요청 때만), 「상상」 표시 없음. 주최 관련 문장은 출처가 있는 사실표에서만.
3. **시트** — 인물(얼굴→전신→시트), 장소(사람·이야기 밖 물건 없음, 있으면 잘라 낸 판), 주최 공식 자료는 원본 그대로 여러 각도.
4. **프리비즈** — three.js 등 회색 대역으로 컷마다 카메라 높이·거리·화각·움직임 수치. 글자 판(확인용)과 글자 없는 판. 영상 모델 참조에는 넣지 않는다.
5. **프롬프트** — 3초 칸 한 줄(샷·카메라·렌즈·움직임·어느 손에 무엇·빛·대사·효과음) + 칸 연결 문장, 에셋 줄 4칸, 고유명사 발음 표기, 장면별 실패 모드 네거티브, 「no cubes / no text」.
6. **생성** — 슬롯 장부로 무제한 자리를 한 번에 한 작업만 쓴다(겹치면 유료·결제 안내가 뜸). 생성마다 화면 가격·무제한 표시·전후 잔액 기록. 하한 아래 유료 금지, 단위마다 재시도 1번. 무제한 30초 클립은 대기 포함 약 1시간으로 잡는다.
7. **후반** — 확대(워터마크 보이면 멈춤) → 장면별 LUT 색 보정 → 편집 → 문장 단위 자막(깔끔한 글꼴·이름표·위치 통일) → 음량 -14 LUFS / -1.5 dBTP.
8. **검수** — 아래 스크립트 세 개 + 1초 장면표 전부 직접 보기 + 받아쓰기 대조 + 대본을 모르는 별도 검수자에게 장면표만 주는 「처음 보는 사람」 검수(꼭 고칠 것 0건일 때만 통과). 못 한 검수는 적는다.
9. **제출** — 최종본·장면표·폼 글 전부를 사람에게 보여 주고 「제출해」를 받은 뒤에만. 폼 함정(글자 수, 숫자 칸, 체크 칸, 응답 수정 불가)과 메일 중복·링크 공개 범위 확인, 완료 화면 캡처.
10. **공개 게시** — 공개 조건을 다시 확인하고 핸들로 채널 확인, AI 표시, 썸네일·고정 댓글, 세로 전용 SNS는 9:16만.
11. **교훈 갱신** — 끝날 때 새 실패를 `references/lessons.md`에 추가하고(원인 확인/미확인 구분), 그 규칙이 실제 작업 지침·점검표·스크립트에 들어갔는지 확인·시험한다. 메모만으로 끝내지 않는다.

## 스크립트 (ffmpeg·ffprobe 필요, Node 18+)

```bash
# 길이: 컨테이너·영상·소리·마지막 패킷 끝이 모두 규정-0.05초 이하인지 (30초 규정 → 29.9초 목표)
node scripts/duration-check.mjs final.mp4 --max 30
# 짧은 컷: 편집 경계에 끼어든 0.5초 미만 컷 찾기 (걸린 시각 앞뒤 프레임은 직접 본다)
node scripts/short-cut-check.mjs final.mp4 --min 0.5
# 1초 장면표: 시각이 찍힌 타일 그림 + 초마다 채울 scenes.md 표
node scripts/scene-sheet.mjs final.mp4 --out qa/scenes
```

종료 코드: 0 통과, 1 불합격, 2 사용법·도구 오류. `FFMPEG`·`FFPROBE` 환경 변수로 도구 경로를 바꿀 수 있다.


## 준비물

| 구분 | 무엇 | 없으면 |
|---|---|---|
| 필수 | ffmpeg·ffprobe, Node.js 18 이상 | 검사 스크립트를 못 돌린다(절차와 점검표는 그대로 쓸 수 있다) |
| 필수 | 공모전 공고 원문과 제출 폼 | 1단계를 할 수 없다 |
| 권장 | 참조 이미지를 받는 영상 생성 서비스(무제한·크레딧 방식 모두 가능) | 프롬프트·점검표는 다른 도구에도 그대로 쓴다 |
| 권장 | three.js 등 간단한 3D 프리비즈 도구 | 콘티 그림과 카메라 수치표로 대신한다 |
| 선택 | 영상 확대 도구, 색 보정 프로그램(LUT), 받아쓰기 도구 | 해당 단계를 건너뛰고 「못 한 검수」에 적는다 |
| 선택 | 대본을 모르는 별도 AI 세션(처음 보는 사람 검수) | 사람 한 명에게 장면표만 보여 주고 묻는다 |

## 바꿔 쓰기: 이렇게 말하면 바뀝니다

| 이렇게 말하면 | 바뀌는 것 |
|---|---|
| "규정이 60초 이내야" | `duration-check.mjs --max 60` (모든 흐름 59.95초 이하) |
| "최소 50초 이상이어야 해" | `--min 50` 추가 |
| "0.3초 미만만 잡아 줘" | `short-cut-check.mjs --min 0.3` |
| "부드러운 장면 전환도 컷으로 잡아 줘" | `--threshold 6`처럼 낮춘다(오탐이 늘어난다) |
| "2초 간격 장면표로" | `scene-sheet.mjs --step 2` |
| "한 장에 4×4로" | `--cols 4 --rows 4` |
| "해설을 목소리로 넣어" | 2단계 기본값(자막 해설)을 바꿔 목소리 해설, 끝소리·받아쓰기 확인 추가 |
| "광고형이라 대사는 적게" | 대사 6~9줄 기준 대신 대사 수를 보고에 적고 결정을 받는다 |
| "이미지 공모전이야" | 4~8단계 대신 시안 여러 장 → 원본 크기 비교 → 고른 이유 → 5단계 제출 점검표 |
