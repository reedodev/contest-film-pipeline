# 실패에서 배운 것 (교훈 표)

실제 공모전 영상·이미지 출품 작업(2026-11-16 ~ 11-24, 영상 9편·이미지 4건)에서 생긴 문제를 모은 표입니다.
형식: **증상 → 원인 → 고친 방법 → 다음부터 지킬 규칙**.
원인 칸의 `(확인)`은 다시 해 보거나 기록으로 확인한 것, `(미확인)`은 추정입니다. 추정을 사실로 옮겨 쓰지 마세요.

작업이 끝날 때마다 맨 아래 「새 교훈 추가 방법」대로 줄을 더합니다.

## 새 교훈 추가 방법 (작업이 끝날 때마다)

1. 이번 작업에서 사람이 지적한 것, 다시 만든 것, 멈춘 것을 모은다.
2. 위 표에 같은 줄이 있으면 그 줄의 규칙을 고치고, 없으면 알맞은 묶음 맨 아래에 새 번호로 추가한다.
3. 원인은 확인한 것만 `(확인)`, 아니면 `(미확인)`.
4. 규칙이 실제 작업 지침(루틴 지침서, 점검표, 스크립트)에 들어갔는지 확인한다. 안 들어갔으면 넣고 시험한다. 메모만 하고 끝내지 않는다.
5. 점검표(`checklists.md`)에 새 항목이 필요하면 추가한다.
