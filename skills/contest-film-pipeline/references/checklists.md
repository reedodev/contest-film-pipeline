# 점검표

각 표를 작업 폴더에 복사해 칸마다 ✓ / ✗ / 해당 없음을 적습니다. ✗가 하나라도 있으면 다음 단계로 가지 않습니다.
괄호 안 번호는 `lessons.md`의 교훈 번호입니다.

## 1. 기획 확정 전 (대본·사실표)

- [ ] 공식 공고 + 공식 폼 첫 화면까지 직접 읽음. 마감 시각, 길이(최소·최대), 비율·해상도, 형식, 제출물 목록, 필수 문구, AI 표기 칸을 규정 메모에 적음 (A1, A3)
- [ ] 공개 조건 세 줄: 발표 전 공개 금지 / 공개 유지 기간 / 마감 뒤 수정 금지. 이미 낸 다른 대회 조건과 충돌 없음 (A4)
- [ ] 규정과 작업 규칙이 충돌하는 곳 없음. 있으면 사람 결정 대기 (A5)
- [ ] 주인공 목표 하나, 막는 것, 웃음이나 반전, 끝 대사가 앞을 받음. 명소·기능 나열 아님 (B1)
- [ ] 첫 3~5초에 누가·무엇을·왜가 나옴 (B2)
- [ ] 대사형이면 30초 묶음마다 대사 6~9줄 (B3)
- [ ] 모든 행동의 이유가 대사나 자막에 한 번 나옴 (B4)
- [ ] 같은 정보 반복 없음 (B5)
- [ ] 해설은 자막(목소리는 요청 때만), 「상상」 표시 없음 (B6, B7)
- [ ] 주최·제품 문장은 모두 사실표(출처 있음)에 있음 (B8)
- [ ] 핵심 물건 이름을 한 번 부르고 정체가 보이는 컷이 있음 (B9)

## 2. 생성 전 (시트·프리비즈·프롬프트·크레딧)

- [ ] 인물 시트: 얼굴·옷·나이(키)가 요청과 같음, 글자·워터마크 없음 (C4)
- [ ] 장소 시트: 사람·얼굴 없음, 이야기에 없는 물건 없음(있으면 잘라 낸 판) (C2, C3)
- [ ] 주최 공식 자료(제품·마스코트·로고)는 새로 그리지 않고 여러 각도 원본 사용 (C9)
- [ ] 프리비즈 컷과 프롬프트 칸이 1:1. 프리비즈 영상은 참조에 넣지 않음 (C1)
- [ ] 프롬프트가 3초 칸 단위, 칸마다 샷·카메라·렌즈·움직임·손·빛·대사·효과음, 칸 연결 문장 있음 (C6, C12, C13)
- [ ] 에셋 줄 4칸 모두 채움 (C7)
- [ ] 같은 장소는 한 구조 그림 기준, 뒤 묶음은 앞 결과 프레임 참조 (C8)
- [ ] 고유명사 발음 표기 (C10). 원치 않는 것을 단어로 적지 않음 (C11)
- [ ] 끝에 「No cubes, no boxes, no text, no subtitles, no logos」
- [ ] 슬롯 장부 확인: 무제한 자리가 비어 있음, 내 이름·시각을 적음 (D1)
- [ ] 화면 가격·무제한 표시·직전 잔액 기록. 생성 뒤 잔액이 하한 위 (D3, D5)
- [ ] 이 단위 재시도 횟수 1회 이하 (D5)
- [ ] 넣은 프롬프트 전문을 파일로 저장 (D7)

## 3. 생성 직후 (클립마다)

- [ ] 직후 잔액 기록, 화면 가격과 차이 없음 (D3)
- [ ] 슬롯 장부를 비움 (D1)
- [ ] 1초 장면표로 얼굴·옷·손·소품 상태·빛·화면 글자·프리비즈 도형 확인 (F1, C1)
- [ ] 주최 제품·마스코트를 공식 그림과 나란히 확대 비교 (C9)
- [ ] 받아쓰기로 대사 대조, 발음이 틀린 단어 표시 (C10)

## 4. 제출 전 (최종본)

- [ ] `duration-check.mjs --max <규정초>` PASS(모든 흐름이 규정-0.05초 이하) (A2)
- [ ] `short-cut-check.mjs` PASS(0.5초 미만 컷 없음), 걸린 곳은 프레임을 직접 봄 (E8)
- [ ] `scene-sheet.mjs`로 1초 장면표 전부 열어 scenes.md 표 채움 (F1)
- [ ] 판정이 걸린 초는 원본 크기로 확인 (F2)
- [ ] 해상도·비율·코덱·용량이 규정과 같음(ffprobe)
- [ ] 자막: 문장 단위, 깔끔한 글꼴, 위치 통일, 얼굴·물건 안 가림, 오타 없음 (E10~E12)
- [ ] 화면 글자를 지운 물건의 모양이 컷마다 같음 (E13)
- [ ] 음량 -14 LUFS 전후, 트루피크 -1.5 dBTP 이하 (E14)
- [ ] 처음 보는 사람 검수 「꼭 고칠 것」 0건, 무슨 이야기인지 이해됨 (F3)
- [ ] 필수 문구·AI 표기가 공고 문구 그대로 (A1)
- [ ] 못 한 검수(이어 보기·직접 듣기)를 보고서에 적음 (F4)
- [ ] 규정 메모를 다시 대조함 (A1)

## 5. 제출할 때 (폼·메일·링크)

- [ ] 사람에게 최종본 + 1초 장면표 + 폼 글 전부를 보여 주고 「제출해」를 받음 (A12)
- [ ] 칸마다 글자 수 한도 확인, 넘치는 내용은 다른 칸으로 (A7)
- [ ] AI 표기 사실대로(글쓰기 AI 역할 포함) (A8)
- [ ] 숫자 칸 값을 입력 뒤 다시 읽음 (A6). 체크 칸은 화면 상태로 확인 (A10)
- [ ] 메일: 보낸편지함에 같은 수신처 0건 → 보낸 뒤 첨부·링크 확인 (A14)
- [ ] 공유 링크가 로그인 없이 열림 (A15)
- [ ] 접수 완료 화면 캡처 저장
- [ ] 정정은 새 응답 + 「앞 응답을 대신」 문장 (A9)

## 6. 공개 게시 (영상 채널·SNS)

- [ ] 공개 조건 세 줄 다시 확인 (A4)
- [ ] 채널을 핸들로 확인, 끝나면 활성 채널 되돌림 (A13)
- [ ] AI 사용 표시 켬, 아동용 아님
- [ ] 맞춤 썸네일·고정 댓글 확인(쇼츠 썸네일 제한은 기록) (A17)
- [ ] 세로 전용 SNS는 9:16만 (A18)
- [ ] 로그아웃 상태에서 공개·길이 표시 확인 (A2)

- [ ] 그 규칙이 실제 작업 지침·점검표·스크립트에 들어갔는지 확인하고 시험
- [ ] 크레딧 기록·인계 메모(완료 파일·주소·남은 일) 정리
